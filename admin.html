连接 GitHub 仓库

内容保存在你自己的 GitHub 仓库里，通过 GitHub API 提交（commit），GitHub Pages 自动发布。Token 只存在你当前浏览器本地，不会上传到别处。

首次使用会检查仓库里是否有 data/works.js，没有就自动创建一份示例内容。

上传素材

点击或拖拽上传作品的图片和视频，可多选。也可以稍后在第 2 步添加图文块。

或把文件拖到这里 · 支持多选

填写信息

标题和作者必填。介绍和硬件清单会显示在首页悬停展开的面板里。

首页预览

这就是作品在首页的样子。左右箭头可切换素材（首页同样支持循环切换）。确认没问题就去发布。

发布

将向 GitHub 提交一次 commit（作品数据 + 新上传的媒体文件），GitHub Pages 通常 1 分钟内更新。

作品管理

编辑或删除已发布的作品。改动保存后才会发布。
